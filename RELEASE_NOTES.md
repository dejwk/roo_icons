# [roo_icons 1.2.4](https://github.com/dejwk/roo_icons/releases/tag/1.2.4)

Published 2026-08-30.

This maintenance release modernizes the build and testing infrastructure.

### What’s changed

- Updated `roo_display` dependency to 3.2.2.
- Updated `roo_testing` to 2.1.1.
- Added `roo_testing` 2.x Arduino ESP32 host profiles.
- Centralized AddressSanitizer configuration.
- Modernized GitHub Actions using the reusable `roo_testing` CI workflow.
- Standardized builds on Bazel 9.2.0.
- Added host-emulation build instructions to the README.
- Updated Arduino and PlatformIO package metadata to version 1.2.4.

There are no icon-set or public API changes in this release.

**Full changelog:** [[1.2.3...1.2.4](https://github.com/dejwk/roo_icons/compare/1.2.3...1.2.4)](https://github.com/dejwk/roo_icons/compare/1.2.3...1.2.4)
